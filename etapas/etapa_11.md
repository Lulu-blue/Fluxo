# Etapa 11 — Gerente antes Infração

## Descrição
O gerente analisa o caso antes da infração e decide o encaminhamento.

## Condições de Saída
| Condição | Destino |
|----------|---------|
| Análise: Indeferido | → Etapa 14 (Auto de Infração) |
| Análise: Deferido | → Etapa 29 (Fiscal Emite Certidão) |
| Análise: Dilatar prazo | → Etapa 3 (Envio da 1ª Defesa) |
| Enviar para o Jurídico | → Etapa 32 (Consulta no Jurídico) |
